# Supply Chain Network Optimization

Portfolio project using mixed-integer optimization to determine which distribution centers to operate and how product should flow from plants to customer regions at minimum annual cost.

## Network
- 3 plants
- 6 candidate distribution centers
- 12 customer regions
- Plant and DC capacity constraints
- Fixed DC operating costs
- Distance-based transportation costs

## Analysis
1. Baseline network optimization
2. Demand +15% scenario
3. Transportation cost +20% scenario
4. DC outage scenario
5. Centralized vs decentralized network comparison
6. Power BI network-cost dashboard

## Methods
- Mixed-Integer Linear Programming (MILP)
- Python / SciPy
- Excel Solver replication
- Scenario analysis
- Power BI

> Synthetic data for portfolio use.
